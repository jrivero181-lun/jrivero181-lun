- **Idempotencia en transacciones:** eliminó la duplicidad de pagos en una app bancaria y redujo la latencia al retirar la detección previa de duplicados.

- **KMP en producción:** módulo compartido de dominio y datos con expect/actual, e interoperabilidad Kotlin–Swift.
